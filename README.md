# Excel Inventory Dashboard

An **Excel-based inventory analytics dashboard** built using **Pivot Tables, Pivot Charts, and interactive filters** to monitor stock performance and inventory value.

This project demonstrates how Excel can be used as a **lightweight business intelligence tool** to transform raw inventory data into meaningful insights for inventory management.

## 🚀 Project Overview

Managing inventory efficiently requires clear visibility into **stock levels, stock value, and inventory trends**.

This dashboard provides a **dynamic overview of inventory data**, allowing users to quickly analyze stock performance across **product categories and suppliers**, and identify **low-stock items** that require replenishment.

The dashboard is built entirely in **Microsoft Excel** using Pivot Tables and slicers, making it simple, flexible, and easy to update with new data.

---

## ✨ Key Features

- 📊 **Inventory Value Overview**  
  Monitor the total value of inventory in stock.

- 📦 **Stock Level Tracking**  
  View current stock quantities across all items.

- 📈 **Inventory Trend Analysis**  
  Analyze stock distribution by **category** and **supplier**.

- ⚠️ **Low Stock Detection**  
  Quickly identify items that are running low.

- 🎛 **Interactive Filtering**  
  Filter the dashboard dynamically by:
  - Product Category  
  - Supplier
